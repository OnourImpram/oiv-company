## Shipped change map

`docs/assets/precision.css` refines tokens, type scale, scene presentation, project composition, visible store rows and contact controls. `docs/assets/site.js` contains original WebGL geometry and material shaders, a static Canvas fallback, scene controls, mobile navigation and a local-only brief builder. `docs/index.html` and `docs/tr/index.html` retain real content and links while exposing published applications and adding the brief UI. `docs/404.html` provides a useful return path.

The scene is artwork, not a model evaluation or a live system status. The project plates are explicitly labelled conceptual illustrations. Existing store labels remain dated to 22 September 2026. OIV is still broader than evaluation services. Clinical effects, independent certification, institutional endorsement, customers and revenue have not been invented.

## Conflicting source guidance

The repositories do not describe one combined library. The approved OIV identity and factual boundaries take priority. Typography remains IBM Plex. Native HTML disclosures remain where they reduce reading load. The dark research section is retained as a deliberate chapter of the established site, not a random theme insertion. Default animation is off. No additional runtime packages, font downloads, analytics, backend endpoint or external image service were added.
